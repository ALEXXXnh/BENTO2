# BENTO2
this is a cute web game, to grab food that looks like pusheen and sushi into a bento box and tidy the bento as you want
**Play demo**
*https://alexxxnh.github.io/BENTO2/bento.html*

## what does the page have?
* a welcome
* a tidy (drag and drop) game that looks like cats
* a page with recipes for your bento box
*a nav bar that looks like a fork

## how was it created?
1. html (web, images, recipes)
2. css (web design, function of scenes display, transitions)
3. javascript (custom cursor, drag&drop events)
